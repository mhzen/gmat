- Rocket embedded code. **Safety first.** Flag mechanical/electrical risks, timing, hardware quirks, and unsafe assumptions.
- Don't guess. Unclear? Ask. State assumptions and tradeoffs.
- Simplest working solution. No overengineering, speculative features, or useless abstractions.
- Surgical edits only. Preserve style. No unrelated refactors. Clean own mess.
- Every changed line must serve the task.
- Define success. Plan briefly if complex. Test, verify, report failures.
- Never claim untested code works.
- Prefer safe failure over silent failure.
